01 / LANGUAGE GENERATION Ongoing research · 2026

Explainable LLM-based Detoxification Framework for Low-Resource Languages

Rewriting toxic Urdu text while preserving meaning and producing fluent language. This research brings together large language models, toxicity classification, and explainability for low-resource NLP.

94.6%Test accuracy
91.6%Fluency score
92.9%Semantic similarity
Research contribution & resources

The supporting Urdu toxicity classifier achieved 93.7% macro-F1 on a held-out test set using XLM-R. The project also includes a parallel Urdu dataset of 2,947 toxic and detoxified text pairs.

This work is ongoing. Contact me about the methodology, code, or dataset.

02 / MULTIMODAL UNDERSTANDING Manuscript under review

Bridging Modalities and Languages

An explainable cross-lingual multimodal deep learning framework for hate speech detection, combining language and image representations across three languages.

3Languages
11,000Instances
88%Test accuracy
Methods & contribution

I developed the end-to-end PyTorch pipeline: preprocessing, balancing, training, evaluation, statistical significance testing, and error analysis. The research combines mBERT, InceptionV3, and tensor fusion; the visual branch uses Grad-CAM for explainability.

The first-author manuscript was submitted to PeerJ Computer Science and is under review.

Multimodal Hate Speech Detection Interface using Advanced Deep Learning

My final-year thesis combines text and image features for hate speech detection using mBERT and Vision Transformer models. An interactive interface supports real-time multimodal analysis.

Research context

This project established my interest in how language and visual information interact in harmful-content detection, and in making deep learning systems usable through an interactive interface.
